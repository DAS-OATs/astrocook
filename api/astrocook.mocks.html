Module contents#

Synthetic quasar spectra with known parameters (mocks).

The generator is independent of the V2 fitting code: it has its own Voigt profile, convolution and pixel integration, so that the fitting code can be tested against it. It shares only the atomic data table (astrocook.core.atomic_data.ATOM_DATA).

Typical use:

from astrocook.mocks import MockComponent, MockTruth, generate

truth = MockTruth(
    components=[MockComponent("CIV", z=2.97, logN=13.5, b=10.0)],
    lam_min_nm=612.0, lam_max_nm=620.0, dv_kms=2.5,
    resol=45000.0, snr=50.0, z_em=3.1, seed=1)
spectrum = generate(truth)          # SpectrumV2
truth.to_json("mock_truth.json")    # ground truth, for later comparison

class astrocook.mocks.MockTruth(components: ~typing.List[~astrocook.mocks.truth.MockComponent], lam_min_nm: float, lam_max_nm: float, dv_kms: float, resol: float | None = 45000.0, snr: float | None = 50.0, z_em: float = 0.0, seed: int = 0, oversample: int = 5, cont_amplitude: float = 1.0, cont_slope: float = 0.0, cont_ref_nm: float = 500.0, emission_lines: ~typing.List[~astrocook.mocks.truth.EmissionLine] = <factory>, n_spikes: int = 0, spike_amplitude: float = 10.0)[source]#

Bases: object

Everything needed to generate, and later evaluate, a mock spectrum.

The wavelength grid is uniform in velocity (pixel size dv_kms), as for echelle spectrographs. The continuum is a power law cont_amplitude * (lambda / cont_ref_nm) ** cont_slope. The noise is Gaussian, with a constant signal-to-noise ratio snr per pixel at the continuum level (None: noiseless).

resol is the resolving power, either a single value or None (no instrumental broadening). oversample is the number of sub-pixels on which the model is computed before being averaged over each pixel.

emission_lines are added to the continuum (the absorbers absorb them too). n_spikes single-pixel positive spikes of spike_amplitude times the local error are added after the noise, at random positions; their indices are not part of the truth but are reproducible from the seed (see astrocook.mocks.spike_indices()).

Mock spectrum for truth.

The spectrum has the true continuum (with emission lines) in the cont column and the noiseless flux in mock_flux; z_em and the resolving power are set (the latter also in the metadata, so that it survives a save).

astrocook.mocks.optical_depth(lam_ang: ndarray, series: str, z: float, logN: float, b: float, btur: float = 0.0) → ndarray[source]#

Optical depth of one component at observed wavelengths (Angstrom).

tau = (pi e^2 / m_e c) f lambda_0 N / (sqrt(pi) b) H(a, u), with u = (lambda_rest - lambda_0) / Delta lambda_D, Delta lambda_D = (b / c) lambda_0, a = Gamma lambda_0 / (4 pi b) and H(a, u) = Re[w(u + i a)].

astrocook.mocks.convolve_velocity(flux: ndarray, dv_kms: float, resol: float | ndarray | None) → ndarray[source]#

Gaussian instrumental convolution on a grid uniform in velocity.

The kernel at each pixel has FWHM = c / R(pixel), so a varying resolution is handled exactly (no grouping of pixels). The flux is extended with its edge values to avoid edge effects.
