astrocook.core.column_names module#

The names of the columns of a spectrum (phase 6-quater, PR 8, F120).

One set of names for the user and the agents: those of the GUI, λ, λmin, λmax, F, dF for the columns that every spectrum has, and the other columns by their own name (cont, model, resol, …). The data keep their own names, x, xmin, xmax, y, dy (the archives, the CSV files of export_ascii, the attributes Spectrum.x, .y, .dy): accepted wherever a column is named, as silent and permanent aliases, as lam, lammin and lammax, the ASCII spelling of λ (Guido, 12 November 2026: shorter than lambda, which is a keyword of Python, e.g. df.lambda in pandas). So the logs, the saved expressions and the scripts written with either set still work, and nothing is translated in them.

The names of the parameters that name an axis and not a column keep x and y (xunit, xstart, dx, x_min of the tools, x_convert).
