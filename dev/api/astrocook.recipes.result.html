astrocook.recipes.result module#

The structured result of a recipe (phase 6-bis, PR 4).

run() runs a recipe of the registry and returns a RecipeResult: the new session (or sessions), what changed in it, listed and not only counted (the components added, removed and changed, the columns, the properties), the warnings the recipe logged, the recipes it ran as steps, and the values of the parameters it used. The GUI, the MCP server and the scripts that want the whole result call it; the methods of the recipes keep returning the session (Guido, decision 1 of the phase).

What changed is found by comparing the session before and after, in one place for every recipe (Guido’s choice at the start of PR 4: a generic comparison, not a description written by each recipe). What a recipe knows and the comparison cannot see (the score of an identification, the groups a fit could not fit) goes in extra, PR 4b; the fields of what the algorithms do not provide yet (the uncertainty of the continuum, the credibility of an identification and its alternatives) are there, empty, so that phase 7 fills them without changing the interface.

astrocook.recipes.result.SAME_PARAMETER_RTOL = 1e-08#

Relative size below which a parameter of a component is the same after a refit: the optimizer returns the values of the start to ~1e-10 and the result listed such components as changed (trial 3 of the MCP server, PR 7)

Say why the components uuids were removed: extra['removed'] maps each to its reason (the comparison lists them, not why).

astrocook.recipes.result.run(session, recipe: str, *, on_missing: str | None = None, **params) → RecipeResult[source]#

Run the recipe recipe ('category.name', or the name alone) on session and return its RecipeResult.

The parameters are given as to the method of the recipe (typed, or as strings); a recipe that cannot do what was asked raises its RecipeError, as the method does. on_missing is the policy for a prerequisite the session lacks, "provide" or "raise" (astrocook.recipes.prerequisites); by default, the one in force.
