Noiseless normalised flux, convolved and averaged over each pixel.

The model is computed on oversample sub-pixels per pixel, convolved with the instrumental profile on that grid, then averaged over the sub-pixels of each pixel.

astrocook.mocks.generate.generate(truth: MockTruth, truth_columns: bool = True) → SpectrumV2[source]#

Mock spectrum for truth.

The spectrum has the true continuum (with emission lines) in the cont column and the noiseless flux in mock_flux; z_em and the resolving power are set (the latter also in the metadata, so that it survives a save).

With truth_columns=False the two columns are left out, as for an observed spectrum: the recipes would otherwise use the true continuum (in the MCP pilot an agent fitted on it). The flux is the same.
