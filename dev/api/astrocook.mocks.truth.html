class astrocook.mocks.truth.MockTruth(components: ~typing.List[~astrocook.mocks.truth.MockComponent], lam_min_nm: float, lam_max_nm: float, dv_kms: float, resol: float | None = 45000.0, snr: float | None = 50.0, z_em: float = 0.0, seed: int = 0, oversample: int = 5, cont_amplitude: float = 1.0, cont_slope: float = 0.0, cont_ref_nm: float = 500.0, emission_lines: ~typing.List[~astrocook.mocks.truth.EmissionLine] = <factory>, n_spikes: int = 0, spike_amplitude: float = 10.0, lyman_limit: bool = False, noise_floor: float | None = None)[source]#

Bases: object

Everything needed to generate, and later evaluate, a mock spectrum.

The wavelength grid is uniform in velocity (pixel size dv_kms), as for echelle spectrographs. The continuum is a power law cont_amplitude * (lambda / cont_ref_nm) ** cont_slope. The noise is Gaussian, with a signal-to-noise ratio snr per pixel at the continuum level (None: noiseless). With noise_floor = None (the default) the error is the same at any flux, cont / snr; with a value a between 0 and 1 it follows the flux, as for photon noise of the source on a background: sigma = (cont / snr) sqrt(a + (1 - a) F / cont), with F the noiseless flux, so that a is the variance at zero flux relative to the continuum.

resol is the resolving power, either a single value or None (no instrumental broadening). oversample is the number of sub-pixels on which the model is computed before being averaged over each pixel.

emission_lines are added to the continuum (the absorbers absorb them too). With lyman_limit the H I components (those with Lyman lines) also absorb the continuum below their Lyman limit (off by default, so that the mocks made before it are unchanged). n_spikes single-pixel positive spikes of spike_amplitude times the local error are added after the noise, at random positions; their indices are not part of the truth but are reproducible from the seed (see astrocook.mocks.spike_indices()).
